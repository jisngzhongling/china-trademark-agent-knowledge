# 文书模板

存放申请、答复、异议、复审、撤销、无效、检索报告和客户意见书模板。模板事实字段必须在使用时重新核验，不得沿用旧案件事实。

`规范用字核验记录模板.md` 用于所有含文字商标的逐字符和分阶段留痕；无异常时也填写案件级结论。原申请标志与建议规范字候选必须分开记录，未经用户明确确认不得据此改字或改图。

电子证据提交默认使用“证据目录 Word + 证据说明 Word + 证据正文 PDF”。`证据提交清单示例.json` 是 `prepare_evidence_submission.py` 的输入模板；目录预留签章位置，每项说明在 Word 中单独起页，证据正文按编号拆分并按页码范围命名。

`证据清单示例.json` 与 `商标证据汇编模板.docx` 保留用于内部检索证据报告或用户明确要求的完整 Word 证据汇编。
